# practice

A new Flutter project.
Features
- Forms & Validation
Validated input fields using TextFormField with length limits and empty checks.
Secure controllers with proper memory management.

- Live Preview & State
Real-time QR code generation using state management and input listeners.
Interactive UI components including a size slider and a reset button.

- Themes & Dark Mode
Material 3 design with light and dark theme switching.
- Animation
Smooth transitions using AnimatedSwitcher when the QR code content updates.
